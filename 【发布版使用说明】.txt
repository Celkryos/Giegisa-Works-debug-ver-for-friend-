Giegisa 桌宠使用说明
====================

一、如何启动

1. 解压整个“Giegisa桌宠”文件夹。
2. 双击 Giegisa.exe。新版单文件发布版已经内置桌宠图片。

发布版已经包含 Python 和程序运行组件，使用者不需要另外安装 Python。


二、首次使用

1. 右键点击桌宠。
2. 打开“核心数据与接口（人设/API）”。
3. 选择接口类型，填写使用者自己的 API Key、接口地址和模型名称。
4. 保存后即可对话。

发布包不会附带制作者的 API Key、聊天记录、便签或私人设置。


三、静默阅读舱

1. 右键桌宠，打开“静默阅读舱（书架/电子书）”。
2. “导入电子书”会把副本放入桌宠旁的 ebook_library 文件夹；
   “从现有文件夹打开”只建立索引，不移动或删除原文件。
3. 支持 TXT、HTML、EPUB、PDF；TXT 会尝试自动识别 UTF-8、GB18030、
   Big5 等编码。
4. 阅读器左侧按钮可打开目录、日夜模式、视觉排版、全文检索、书签批注、
   自动阅读和其它设置。
5. 阅读目标可以同步到日历的“每日阅读”打卡项目。


四、程序产生的个人文件

首次使用后，程序会在 Giegisa.exe 旁边自动产生：

- config.json：接口、设置、好感度、日程和收藏等数据。
- history.json：聊天记录。
- notes.txt：便签的纯文本备份。
- ebook_library：导入书架的电子书副本、解析图片和阅读资源。
- 对应的 .bak 文件：自动备份。

这些文件可能包含隐私。转发软件时不要把它们一起发送。


五、Windows 安全提示

这是个人制作、没有购买商业数字签名的软件。
Windows 可能显示“未知发布者”或 SmartScreen 提示。
请只从你信任的发送者处接收并运行，不要随意关闭杀毒软件。


六、常见问题

1. 桌宠显示灰色方块：
   旧版可能缺少 pictures 文件夹；新版单文件发布版已内置图片。

2. 无法对话：
   检查 API Key、接口地址、模型名称和网络连接。

3. 换电脑后保留记忆：
   退出程序后，复制 config.json、history.json、ebook_library 和相关 .bak
   文件到新目录。

4. 想获得全新存档：
   先备份私人数据，再删除 config.json、history.json 和 notes.txt。
